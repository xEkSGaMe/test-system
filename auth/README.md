# 🔐 Auth Service (Go) — СТАТУС: READY 🚀

Сервис аутентификации на Go (Gin), обеспечивающий безопасность всей тестовой системы. Полностью контейнеризирован и интегрирован с базой данных и кэшем.

## 🛠 Технологический стек
- **Язык:** Go 1.23
- **Фреймворк:** Gin Gonic
- **База данных:** PostgreSQL (хранение пользователей и сессий)
- **Кэш:** Redis (черный список токенов / Logout)
- **Контейнеризация:** Docker + Docker Compose

## ✅ Что реализовано (100%)
- [x] **Регистрация и Логин:** Классическая схема с хешированием паролей.
- [x] **OAuth2 Yandex:** Полная интеграция, автоматическое создание профиля.
- [x] **OAuth2 GitHub:** Полная интеграция (через Developer Settings).
- [x] **JWT сессии:** Выдача пар Access (15m) и Refresh (24h) токенов.
- [x] **Rotation:** Механизм обновления Refresh-токенов.
- [x] **Безопасность:** Инвалидация токенов через Redis при выходе (Logout).
- [x] **Infrastructure:** Автоматические миграции БД при запуске контейнера.

## 🚀 Запуск
```powershell
docker-compose up -d --build auth-service

📦 Инфраструктура
Сервис работает в связке с:

Postgres: порт 5432 (БД test_system)

Redis: порт 6379 (DB 0)

Auth API: порт 8081



Метод,Путь,Описание
GET,/auth/yandex/login,Вход через Яндекс
GET,/auth/github/login,Вход через GitHub
POST,/auth/register,Регистрация нового пользователя
POST,/auth/login,Авторизация (Email/Password)
POST,/auth/refresh,Обновление пары токенов
POST,/auth/logout,Мгновенный выход (Blacklisting)
GET,/auth/me,Получение данных текущего профиля
